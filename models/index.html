Models

Models and languages

Compare WhisperInc's local speech and text models, supported languages, download sizes and device requirements.

WhisperInc uses on-device models for speech recognition and optional text rewriting. Downloadable model sizes and 1–5 ratings below are catalog estimates; actual storage use can vary. System models are provided by Apple and have no model download. Ratings are catalog comparisons, not a guarantee of results on every recording.

Speech-to-text

These models turn a recording into a transcript. Whisper supports 99 languages; Parakeet Ultra supports 25 European languages including Polish; Parakeet v2 is English-only. Apple Speech supports 22 languages and does not support Polish.

Text rewriting

Text models optionally turn a transcript into a message, email or other text using the instructions in a mode. Qwen and Gemma run locally through MLX. Apple Intelligence is a system model, requires Apple Intelligence to be available, and does not support Polish.

Which model should I choose?

  • For a good balance of speed and recognition across many languages, start with Whisper Large v3 Turbo.
  • For very fast recognition of Polish or another supported European language, try Parakeet Ultra.
  • For English-only recognition, Parakeet v2 is a very fast option.
  • For a smaller speech-model download, try Whisper Base or Small; Tiny is the smallest option.
  • For Polish rewriting, Qwen 3.5 2B or Gemma 4 are catalog options. Larger models need more memory and storage.
  • Apple system models need no model download, but availability depends on the language, OS and device.

Models may be listed but unavailable on a device when the platform artifact, language support or minimum memory requirement is not met. macOS requires macOS 26 or later on Apple Silicon; iPhone requires iOS 26 or later. MLX text models do not run in the iOS Simulator.
